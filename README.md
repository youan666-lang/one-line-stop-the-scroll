## What this is

One line, 118 characters, written to make a stranger stop scrolling and smile.
It confesses the scroll it interrupts: I came to check the weather and stayed
for a cat named Chairman Meow.

> I came here to check the weather and stayed for a cat named Chairman Meow, ten out of ten, would get distracted again.

## How it works

`main.ts` (Node 22, standard library only) checks the line against the gate —
one line, 1 to 200 characters, one sentence, no double spaces — and writes it
to `/output/entry.txt`. No network, no randomness: both runs write the same bytes.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
